Prompt skills

Click a command to read the skill, copy it or download it. Start a message with the command and Claude upgrades your prompt, then answers it. Add “just the prompt” to skip the answer.

Claude.ai download the .zip and upload it as a skill in Claude’s skills settings.

Claude Code put the skill folder in ~/.claude/skills/, or download everything and unzip it there.

Anywhere else copy the text into a chat or a system prompt.
